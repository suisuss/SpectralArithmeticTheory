# Vector-Valued Observation: Escaping the Scalar Bottleneck

## The Problem

The derivation barrier identifies a scalar bottleneck: when observation maps algebraic terms to a single number (countF0, size, etc.), collisions are inevitable. With 8 assignments and a 1-dimensional output, distinct assignments map to the same value.

The fix is dimensional: map each assignment's term to a *vector*, not a scalar. In d dimensions, you can have d linearly independent directions — d collision-free channels of information. The derivation barrier constrains scalar observation (d=1). Vector observation (d >> 1) is the natural escape.

---

## Existence Proof: XOR-SAT

XOR-SAT (systems of linear equations over GF(2)) is in P. The reason is precisely that it has a collision-free vector space embedding:

- Each XOR clause (x₁ ⊕ x₂ ⊕ x₃ = 1) is a linear equation
- The system of m clauses is a matrix A ∈ GF(2)^{m×n}
- Satisfiability = does Ax = b have a solution? = rank condition on [A|b]
- Each clause maps to a ROW VECTOR in GF(2)^n
- AND of clauses = stacking rows (matrix construction) — a LINEAR operation
- No collisions: distinct clauses are distinct vectors

The key property: in XOR-SAT, both the clause operation (XOR) and the conjunction operation (AND-of-XORs = system of equations) are linear. The entire problem lives in a vector space, and linear algebra solves it in O(n³).

CNF-SAT replaces XOR with OR. OR is non-linear: OR(a,b) = a + b - ab. The -ab term breaks linearity. This is the source of NP-hardness — or at least, this is where the vector space structure breaks down.

## The Embedding Question

Can we embed CNF clauses into a vector space such that:

1. **Each clause maps to a vector** in some space V
2. **AND (conjunction) maps to a linear operation** on V (addition, matrix multiplication, or similar)
3. **Satisfiability is a linear-algebraic property** of the resulting vector (nonzero, full rank, etc.)
4. **The dimension of V is polynomial** in the number of variables

If all four hold, SAT is in P. If (4) necessarily fails (dimension must be exponential), that's evidence for P ≠ NP. If (2) necessarily fails (AND can't be linearized), that's a structural obstruction.

### What's known

**Nullstellensatz proof system**: Encode each clause as a polynomial. The formula is unsatisfiable iff 1 is in the ideal generated by the clause polynomials. The polynomial ring is a vector space (monomials as basis). AND corresponds to ideal membership. Satisfiability corresponds to whether the ideal is the whole ring.

Degree-d Nullstellensatz checks whether 1 can be written as a degree-d combination of clause polynomials. This is a linear algebra problem in the vector space of degree-d monomials, which has dimension O(n^d). For hard instances, d must be Ω(n), giving exponential dimension. This is a proof complexity lower bound (Ben-Sasson, Wigderson).

**Polynomial Calculus**: Extends Nullstellensatz with a derivation rule — you can derive ∂p/∂xᵢ from p. The derivation introduces... a derivation. This connects directly to our framework. Polynomial Calculus degree lower bounds show that derivation doesn't help enough for hard instances.

**Sherali-Adams / Sum-of-Squares**: Lift into higher-dimensional spaces via moment matrices. Satisfiability corresponds to the existence of a positive semidefinite matrix satisfying linear constraints. Again, the dimension of the matrix grows, and for hard instances, the required lift size is exponential.

**Extended formulations**: The satisfying assignments form a polytope in {0,1}^n. Any linear program that solects SAT must have a feasible region that projects onto this polytope. The extension complexity (minimum dimension of a lifted polytope) is exponential for the correlation polytope (Fiorini et al. 2012, 2015). This is a formal proof that linear programs can't solve SAT in polynomial size.

### The pattern

Every known vector space approach to SAT requires exponential dimension for hard instances. The proofs use different techniques:
- Nullstellensatz: degree lower bounds
- Extended formulations: communication complexity / factorization of the slack matrix
- SOS: pseudo-expectation arguments

But the conclusion is the same: you can embed SAT into a vector space, but the dimension blows up.

## A Different Angle: Vectors as Observations, Not Encodings

The approaches above embed the PROBLEM into a vector space. There's a different strategy: keep the problem in its native representation, but make the OBSERVATION vector-valued.

Instead of:
```
assignment → term → scalar measure → collision
```

Do:
```
assignment → term → vector of measurements → no collision
```

The vector could be:
- (countF0, countF1, countZ, countOplus, countCompose, termSize) — a 6-dimensional observation
- The depth profile: (nodes at depth 0, nodes at depth 1, ..., nodes at depth k) — a k-dimensional observation
- The subtree hash spectrum: hash each subtree, take the multiset as a high-dimensional fingerprint
- Heat kernel signature: run diffusion on the tree, measure heat distribution at t time steps — a continuous family of observations

### What the DynSemiring data says

At depth 5, the DynSemiring observations for all 8 assignments are:

| Measure | Depends on |
|---------|-----------|
| countF0 | Nothing (= 92 for all) |
| countF1 | Truecount only |
| countZ | Uniform |
| countOplus | Uniform |
| countCompose | Truecount only |
| termSize | Truecount only |

The 6-dimensional vector (countF0, countF1, countZ, countOplus, countCompose, termSize) collapses to effectively 2 dimensions: a constant and a truecount-dependent value. All 8 assignments map to at most 4 distinct vectors (one per truecount value: 0, 1, 2, 3). Since SAT and UNSAT assignments share truecount values, 4 dimensions aren't enough.

But the depth profile might have more structure. The diffusion analysis found structural differences at depth 10 — the trees ARE different, just not in ways scalar measures can see. A depth profile observation might have enough dimensions to separate.

### The depth profile as a vector

Define: for a term t and depth d, let profile(t) = (n₀, n₁, n₂, ..., n_k) where nᵢ = number of nodes at depth i.

If the profile vector is different for SAT vs UNSAT assignments, separation is achieved with a vector-valued observation — no scalar bottleneck.

The diffusion analysis suggests this might work: the first structural difference between SAT assignment 010 and UNSAT assignment 001 appears at depth 10. Their depth profiles must differ at position 10 or beyond.

This would NOT violate the derivation barrier (which is about scalar measures). It would show that the terms contain the satisfiability information — it's just not extractable by 1-dimensional projection.

## The AND Linearization Problem

The deepest question: can AND be made linear in some vector space?

### Why AND is non-linear

AND(a,b) = a * b. In any ring, multiplication is bilinear but not linear: AND(a + b, c) = AND(a,c) + AND(b,c) (distributes), but AND(a,b) is degree 2 in the inputs. A single AND is a bilinear map V × V → V, not a linear map V → V.

This means a formula with m ANDs produces a degree-2^m polynomial in the variables. The exponential blowup IS the non-linearity of AND, manifested algebraically.

### Tensor product: the canonical linearization

There is a standard way to linearize a bilinear map: tensor product. AND(a,b) = a * b is bilinear; the universal property of ⊗ says there exists a unique linear map L such that:

```
AND(a,b) = L(a ⊗ b)
```

where a ⊗ b lives in V ⊗ V. If V has dimension d, then V ⊗ V has dimension d². After m tensor products (m ANDs), the space has dimension d^{2^m} — exponential.

This is the "correct" linearization, but it's exponential. The question is whether the structure of CNF formulas allows compression.

### Structured compression: can CNF avoid the exponential?

CNF formulas are not arbitrary conjunctions. They have structure:
- Each clause involves at most k variables (k-SAT)
- Clauses share variables (the clause-variable incidence graph)
- The satisfying assignments form a structured subset of {0,1}^n

Can this structure allow a polynomial-dimensional embedding?

**Tensor networks**: In physics, tensor networks (MPS, PEPS, MERA) represent exponentially large tensors in polynomial space by exploiting local structure. A CNF formula with bounded treewidth has a polynomial-size tensor network representation. Satisfiability can be computed in polynomial time for bounded-treewidth formulas — this is a known result.

For general CNF (unbounded treewidth), tensor networks require exponential bond dimension. This parallels the extension complexity results.

**Randomized linearization**: Instead of exact linearization, approximate AND with a randomized linear map. This is essentially what Shamir's protocol does — evaluate the polynomial at a random point, which is a random linear functional on the coefficient vector. The randomness breaks the symmetry that deterministic scalar observation can't break.

## Connection to the Derivation Barrier

The derivation barrier says: scalar observation through a derivation on a commutative algebra can't separate SAT from UNSAT.

The vector observation escape says: use higher-dimensional observation to avoid the scalar bottleneck.

The connection to existing proof complexity:

| Proof system | Observation type | AND operation | Dimension | Separates SAT? |
|-------------|-----------------|---------------|-----------|----------------|
| DynSemiring obs | Scalar (count nodes) | compose (commutative mult) | 1 | No |
| Depth profile | Vector (nodes per depth) | compose | O(depth) | Open |
| Nullstellensatz | Vector (coefficient space) | Ideal membership | O(n^d) | Yes, but d can be Ω(n) |
| Polynomial Calculus | Vector + derivation | Ideal + differentiation | O(n^d) | Yes, but d can be Ω(n) |
| SOS / Sherali-Adams | Matrix (PSD lift) | Moment constraints | O(n^d) | Yes, but d can be Ω(n) |
| Extended formulations | Polytope lift | Linear constraints | Exp (proven) | N/A |
| Shamir | Randomized scalar | Polynomial evaluation | 1 + randomness | Yes (for IP) |

The pattern: increasing the observation dimension increases the power. Scalar fails (derivation barrier). Polynomial-dimensional vector works but may require exponential degree/dimension for hard instances. Randomized scalar works for interactive proofs but doesn't resolve P vs NP.

## Research Directions

### 1. Formalize the depth profile observation

Compute the depth profile vector for all 8 DynSemiring assignments at depth 5 normalization. If the vectors differ for SAT vs UNSAT assignments with the same truecount, that's a concrete demonstration that vector observation escapes the scalar barrier.

This is directly testable in Lean: add a function that computes the depth profile as a list of natural numbers, and check whether SAT assignments have distinct profiles from UNSAT assignments.

### 2. Characterize the minimum observation dimension

What is the minimum dimension d such that a d-dimensional observation of DynSemiring-normalized terms separates SAT from UNSAT? This is a concrete measure of "how much information the scalar bottleneck loses."

- d = 1: insufficient (derivation barrier)
- d = ?: sufficient
- d = termSize: trivially sufficient (the full term is an observation)

The interesting question is whether d is polynomial in the formula size.

### 3. Connect to proof complexity

The observation dimension maps onto proof system strength:
- Scalar observation ≈ very weak proof system (can't prove anything about SAT)
- Polynomial-dimensional observation ≈ bounded-degree Nullstellensatz / Polynomial Calculus
- Full term observation ≈ unrestricted proof system

If the minimum observation dimension for DynSemiring terms matches known proof complexity bounds (e.g., the Nullstellensatz degree for the same formula), that would connect the spectral arithmetic framework to established complexity theory.

### 4. The key question: polynomial dimension with linear AND?

Is there a vector space V of polynomial dimension and a linear operation L : V → V such that:
- Each clause maps to a vector in V
- L represents conjunction (AND of clauses)
- Satisfiability is a linear-algebraic property of the resulting vector

The extension complexity results (Fiorini et al.) show this is impossible for linear programs. But the question is open for other algebraic structures. The SOS/Lasserre hierarchy works in a lifted space where the answer is yes but the dimension can be exponential. Whether there exists a polynomial-dimensional algebraic structure where AND is linear and SAT is decidable is essentially equivalent to P vs NP.

This is the question at the bottom of everything: can you linearize AND in polynomial dimension?
